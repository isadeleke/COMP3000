# Heart Disease Prediction with Explainable AI

## Project Overview

This project aims to develop a machine learning system that predicts the presence or absence of heart disease using clinical measurements.

The project will also incorporate Explainable AI (SHAP) to explain the features contributing to individual model predictions.

## Datasets

The project uses four datasets from the UCI Heart Disease collection:

- Cleveland
- Hungarian
- Switzerland
- Long Beach VA

Cleveland is intended for model training, while the other datasets will be used for independent external evaluation.
